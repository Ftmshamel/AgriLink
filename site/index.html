Install on your phone

  1. Scan the code or tap Download, then open AgriLink.apk.
  2. If Android says installs are blocked, tap Settings and allow this source.
  3. Tap Install. If an older AgriLink is already on the phone and Android says it cannot install, uninstall the old one first.
  4. Open AgriLink and log in. New here? Use Forgot password? to set one.
